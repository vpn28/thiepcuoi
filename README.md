## Thông tin cưới

- **Cô dâu**: Hương Quỳnh
- **Chú rể**: Ngọc Vân  
- **Ngày cưới**: 21/12/2025
- **Giờ**: 12:00 PM

## Cấu trúc file

- `index.html` - Trang chính
- `styles.css` - File CSS styling
- `script.js` - File JavaScript xử lý logic

## Chạy local

1. Mở terminal tại thư mục dự án
2. Chạy Python HTTP server:
   ```bash
   python -m http.server 8000
   ```
3. Mở trình duyệt: `http://localhost:8000`
